The Engineering Challenge

Mobile self-care applications serve as the primary customer interface for telecommunications providers in Bangladesh. However, user reviews are extremely fragmented and linguistic, combining pure Bengali script, formal English, and code-mixed phonetic Banglish. Traditional keyword matching fails on nuances like sarcasm, localized telecom slang (e.g., "megabyte kete niyeche"), or specific complaints regarding balance recharges and OTP delivery delays.

Pipeline Architecture

The solution was built as a multi-stage data processing pipeline:

  • Automated Ingestion: Python script extracting raw user reviews, timestamps, ratings, and app version numbers across MyGP, MyBL, and MyRobi.
  • Semantic Classification: Implemented batch prompt pipelines using LLM APIs to categorize feedback into standardized issue vectors: Billing/Recharge, Network/Connectivity, UI/UX Friction, and Promotional Spam.
  • Data Modeling: Modeled a clean star schema with a central sentiment fact table linked to dimension tables for operators, date calendars, and issue taxonomies.

Business Intelligence & DAX Measures

The modeled dataset was connected to Power BI to provide executive-level monitoring:

  • Net Sentiment Score (NSS): Custom DAX metric tracking $(% \text{ Positive} - % \text{ Negative})$ over time across releases.
  • Feature Regression Detection: Automated flags identifying sudden drops in user ratings directly correlated with specific mobile app build updates.
