#### 1.2 Code-Mixed Text Normalization & Hybrid Vectorization
- **Normalization Cascade** (`paper/eswa_latex/manuscript.tex:111-114`):
  $$T_i^* = \mathcal{N}_{\text{slang}}\!\left(\mathcal{N}_{\text{punct}}\!\left(\mathcal{N}_{\text{case}}\!\left(\mathcal{N}_{\text{unicode}}(T_i)\right)\right)\right)$$
  - $\mathcal{N}_{\text{unicode}}$: strips zero-width non-joiners (ZWNJ) and normalizes decomposed Bengali UTF-8 (`NFKD`).
  - $\mathcal{N}_{\text{case}}$: uniform Latin lowercasing.
  - $\mathcal{N}_{\text{punct}}$: isolates emoticons/punctuation while retaining sentence boundaries.
  - $\mathcal{N}_{\text{slang}}$: standardizes phonetic Banglish spelling variants (e.g., `"faltu"`, `"fal2"`, `"faaltu"` $\to$ root lemma *faltu*).
- **Hybrid Feature Representation:**
  - Manuscript equation (`manuscript.tex:118`): $\mathbf{x}_i = \left[\mathbf{x}_{i,\text{char}(2-5)} \;\|\; \mathbf{x}_{i,\text{word}(1-3)}\right] \in \mathbb{R}^D$ with sublinear TF scaling ($1 + \log(\text{tf})$).
  - *Implementation nuance in code:* `ml/train_category.py:84-96` implements a `FeatureUnion` of `word_tfidf(ngram_range=(1, 2), min_df=2, sublinear_tf=True)` + `char_tfidf(analyzer="char_wb", ngram_range=(3, 5), min_df=3, sublinear_tf=True)` (matching `manuscript.tex:282` Table 2: `Word (1--2) + Char (3--5)`), whereas `ml/train_ensemble.py:47-52` (sentiment) uses `TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 5), min_df=3, sublinear_tf=True)`.

#### 1.3 Asymptotic Complexity & Throughput Benchmarks
- **Time & Space Complexity** (`manuscript.tex:172-173`):
  - Let $L$ = review char length, $V \approx 50{,}000$ sub-word n-gram vocab size, $d \approx 20\text{--}45 \ll V$ non-zero features per review, $K \in \{3, 5\}$ output classes.
  - Normalization & hashing: $\mathcal{O}(L)$; sparse dot-product scoring: $\mathcal{O}(d \cdot K)$; soft-voting aggregation: $\mathcal{O}(K)$.
  - **Total Inference Complexity:** $\mathcal{O}(L + d \cdot K)$ time and $\mathcal{O}(V \cdot K)$ memory — bypassing quadratic transformer self-attention $\mathcal{O}(L^2 \cdot D)$.
- **5-Fold Stratified CV Leaderboard & Hardware Latency** (`manuscript.tex:272-292`, `ml/reports/category_benchmark_summary.csv:1-6`, `dl/README.md:57-79`):
  - **Hero Soft-Voting Ensemble** (`LR w=2 + Calibrated LinearSVC w=2 + ComplementNB w=1`, weights `[0.40, 0.40, 0.20]`):
    - Category (5-Class): **87.44% ± 0.88% Acc**, **0.7845 ± 0.019 Macro-F1**, **0.8738 Weighted-F1**, **1.42 ms/review** (`450 rps` on Intel Xeon CPU 2.20 GHz).
    - Sentiment (3-Class): **87.47% Acc**, **0.7684 Macro-F1** (`README.md:334`, `dl/README.md:60`). *(Note: `dl/README.md:60` cites ~17.5k rev/s batch throughput, while `manuscript.tex:282,292` standardizes single-review end-to-end production pipeline throughput at **1.42 ms / 450 rps** vs. BanglaBERT **32.6 ms / 12 rps** = **37.5×** speedup; `README.md:399` also notes `>80×` speedup vs unbatched DL.)*
  - **BUET BanglaBERT (Full Fine-Tuned, `csebuetnlp/banglabert`, 110M params, 12 layers):**
    - Category: **85.27% ± 1.10% Acc**, **0.7611 ± 0.025 Macro-F1** (`manuscript.tex:286`; `dl/README.md:76` lists `0.7624`), **0.8527 Weighted-F1**, **32.6 ms / 12 rps** on NVIDIA T4 GPU (`+10.39%` leap over Frozen Backbone `74.88% / 0.6253`, `45.0 ms`).
    - Sentiment: **91.60% Acc**, **0.8598 Macro-F1** (`+12.20%` over Frozen `79.40% / 0.6820` — `manuscript.tex:324`, `dl/README.md:59`, `update_banglabert.py:9-10`).
  - **Other Baselines (`manuscript.tex:276-288`):** Dummy Floor (`60.68% / 0.1511`), ComplementNB (`84.21% / 0.7418`, `0.45 ms`), Balanced LR (`86.44% / 0.7781`, `0.82 ms`), Calibrated LinearSVC (`87.09% / 0.7687`, `0.95 ms`), Hybrid BiLSTM+Attn (`80.84% / 0.7106`, `18.4 ms` GPU), Multilingual MiniLM (`81.15% / 0.7247`, `14.1 ms` GPU).
  - **Pairwise Significance Tests (`manuscript.tex:292`):** 5-fold paired $t$-tests confirm Hero Ensemble > ComplementNB ($t(4)=4.82, p=0.008$), > Hybrid BiLSTM ($t(4)=7.15, p=0.002$), > Heuristic ($t(4)=48.3, p<0.0001$); McNemar's test on Human Gold ($N=300$) vs star-rating heuristic: $\chi^2(1)=21.64, p<0.0001$.

#### 1.4 ComplementNB Bayesian Probability Regularization & Platt Scaling
- **Ensemble Formula** (`manuscript.tex:159-170`, `ml/train_ensemble.py:54-64`, `ml/train_category.py:103-132`):
  - LinearSVC calibrated via Platt sigmoid: $P(y=c \mid f(\mathbf{x})) = \frac{1}{1 + \exp(A f(\mathbf{x}) + B)}$.
  - Soft voting: $\hat{\mathbf{p}}_i = \sum_{m=1}^3 \omega_m P_m(y \mid \mathbf{x}_i)$ with $\boldsymbol{\omega} = [0.40, 0.40, 0.20]$ (LR $w=2$, Calibrated LinearSVC $w=2$, `ComplementNB(norm=True)` $w=1$).
- **Calibration Effect (`README.md:393-400`, `scripts/build_paper_html.py:1039`):**
  - Removing `ComplementNB` produces **zero discrete label disagreements** on both the $N=300$ held-out gold test set and $N=5,000$ corpus sample (`README.md:394`).
  - Statistically, `ComplementNB` acts as an entropy / Bayesian prior regularizer over class-complement log-likelihood ratios, taming mean maximum predicted confidence from **84.76% down to 74.47%** (eliminating overconfident tail spikes while preserving discrete classification decisions and CPU latency).

#### 1.5 Rogan-Gladen Prevalence Adjustment
- **Estimator Equation** (`manuscript.tex:176-180`):
  $$p^* = \frac{\hat{p} + \mathrm{Sp} - 1}{\mathrm{Se} + \mathrm{Sp} - 1}$$
  where $\hat{p}$ is raw observed negative prevalence, $\mathrm{Se} = 0.711$ (empirical negative sensitivity/recall from gold validation: `data/gold_set/gold_standard_evaluation_report.md:49`), and $\mathrm{Sp} = 0.942$ (`manuscript.tex:627`), confirming true operator NSS values stay within a narrow **$\pm 2.4$ percentage-point envelope** preserving all operator rankings (`scripts/build_paper_html.py:1562`).

#### 2.4 Four Qualitative Linguistic Failure Modes (`manuscript.tex:372-378`, `paper/eswa_latex/update_paper.py:40-46`)
Analyzed across discordant predictions between Soft-Voting Ensemble, BUET BanglaBERT, and double-blind human consensus:
1. **Sarcasm & Inverted Sentiment Polarity:** Praise tokens (e.g., `"osadharon"` [extraordinary], `"ki sundor"` [how beautiful]) juxtaposed with crashes (*"osadharon app! login korte gele crash kore, ki sundor service!"*). Sub-word TF-IDF assigns false positive ($P(\text{Pos})=0.84$), whereas BanglaBERT self-attention captures clause inversion ($P(\text{Neg})=0.91$).
2. **Polysemous Slang & Colloquial Deception Terms:** Vernacular grievance terms (`"batpari"` [swindling], `"dakat"` [robbers], `"MB joma"` — e.g., *"bhai pack kinlam kintu MB joma hoilo na, shob batpari"*) infrequently co-occur with formal billing lexicon, causing linear routing to `General/Other` rather than `Billing`.
3. **Multi-Issue Boundary Overlap:** Compound grievances across client + RF layers (*"network e speed nai ar app open korlei crash kore"*). Mutually exclusive single-label classification assigns `Network` ($p=0.54$) while suppressing concurrent `App Login/Defect` ($p=0.42$), motivating future multi-label extensions.
4. **Ultra-Short Low-Context & Phonetic Variants:** Isolated pejoratives or phonetic spelling mutations (`"fultu"` vs `"faltu"`, `"baje"`, 1-star empty strings) lack dense syntactic context; sub-word char n-grams partially rescue OOV tokens.

#### 4.1 Canary Release Gating — Algorithm 1 (`manuscript.tex:533-574`)
Complementary semantic diagnostic circuit breaker alongside APM tools (e.g., Firebase Crashlytics) during phased canary rollouts (e.g., 5% initial cohort):
- **Input Parameters (`manuscript.tex:550`):**
  - Stream $\mathcal{R}_{\text{canary}} = \{r_1, \dots, r_n\}$
  - Adaptive observation window $W \in [30, 100]$ reviews
  - Significance threshold $\alpha = 0.01$
  - Historical baseline defect rate $p_{\text{base}} = 0.046$ (`4.6%`)
  - Emergency abort threshold $\tau_{\text{abort}} = 0.12$ (`12%`)
- **Algorithmic Logic (`manuscript.tex:552-569`):**
  1. Initialize $N_{\text{canary}} \leftarrow 0$, $N_{\text{login\_neg}} \leftarrow 0$.
  2. For each review $r_i$, infer $(\hat{c}_i, \hat{s}_i)$; increment $N_{\text{login\_neg}}$ if $\hat{c}_i = \text{App Login \& Technical Bugs}$ AND $\hat{s}_i = \text{Negative}$; increment $N_{\text{canary}}$.
  3. Once $N_{\text{canary}} \ge W$, compute exact binomial test $p_{\text{val}} \leftarrow \text{BinomialTest}(k = N_{\text{login\_neg}}, n = N_{\text{canary}}, p = p_{\text{base}})$.
  4. **Decision Gate:**
     - If $p_{\text{val}} < \alpha$ AND $(N_{\text{login\_neg}} / N_{\text{canary}}) \ge \tau_{\text{abort}}$ $\to$ **`ROLLBACK`** (halt CI/CD rollout & reroute traffic).
     - Else if $p_{\text{val}} < \alpha$ $\to$ **`HOLD`** (Alert Level 2: freeze expansion & flag engineering triage).
     - Else $\to$ **`PROCEED`** (advance rollout tier).
