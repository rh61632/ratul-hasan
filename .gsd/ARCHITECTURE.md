## Data Flow

1. **Landing Page Bootstrap (`index.html` -> `js/app.js`):**
   - Browser parses `index.html`, executes inline `tailwind.config` (`index.html:15-44`), applies `css/styles.css?v=3.0` (`index.html:45`), and loads ES module entrypoint `js/app.js?v=2.9` (`index.html:548`).
   - On `DOMContentLoaded` (`js/app.js:14`), `initThemeToggle()` syncs `dark` class from `localStorage.theme` or OS preference (`js/theme.js:1-19`).
   - `app.js` passes arrays from `js/data/*.js` into `renderProjects`, `renderAwards`, `renderSpeaking`, `renderPosters` (`js/app.js:19-28`) and directly populates `#experience-list`, `#audit-card`, `#training-courses`, `#field-visits` (`js/app.js:31-316`).
   - When an item has `media: null` (e.g., TICI training, 132/33 kV Substation, Bheramara 410MW), `getThemedHeaderMarkup()` injects an inline themed SVG header (`js/app.js:162,238`, `js/components/cardBanners.js:8-417`).
2. **Card Interaction & Page Navigation:**
   - **Desktop (`>=1024px`):** Hovering cards in `#projects-grid`, `#awards-grid`, or `#speaking-grid` expands `flex: 2.75` and swaps collapsed/expanded summaries and footers via CSS (`css/styles.css:67-177`). Clicking opens `caseStudyUrl` via `window.navigateToProject(url)` (`js/app.js:319-328`), saving `window.scrollY` to `sessionStorage.portfolio_scroll_y`.
   - **Mobile/Tablet (`<1024px`):** Cards snap into horizontal scroll tracks (`css/styles.css:190-245`) with mouse drag-scroll (`js/app.js:622-671`). First tap toggles `.is-active`; second tap navigates (`renderProjects.js:144-156`, `renderAwards.js:159-171`, `renderSpeaking.js:151-163`).
   - **Returning from Case Study:** `projects/*.html` back links call `window.history.back()` when coming from the same host (`projects/asian-marble.html:73`); `js/app.js:708-725` detects `back_forward` navigation and restores `sessionStorage.portfolio_scroll_y`.
3. **Poster Lightbox Flow (`js/components/renderPosters.js`):**
   - Clicking any poster preview or `View Full` button (`renderPosters.js:116-126`) lazily creates `#posterModal` (`130-200`), populates `poster.fullImageUrl` and `poster.pdfUrl`, and locks body scroll until closed via button, backdrop click, or `Escape`.
4. **Offline Thumbnail Pipeline (`scripts/generate_thumbnails.py`):**
   - Developer runs `scripts/generate_thumbnails.py` locally with Pillow (`requirements.txt:2`) to resize images from `awards/`, `projects/`, and `visits/` into `assets/images/thumbnails/`, which are then committed to git and referenced statically in `js/data/*.js` and `projects/*.html`.

## Conventions

**Naming:**
- HTML case study pages and asset folders use `kebab-case` (`hall-dining-erp.html`, `asian-marble/`, `khulna-330/`), while JS data/component files use `camelCase` (`renderProjects.js`, `cardBanners.js`, `projectsData`) and Python uses `snake_case` (`generate_thumbnails.py`).

**Structure:**
- Landing page data is decoupled from markup (`js/data/*.js` -> `js/components/*.js` -> `js/app.js` -> `index.html`).
- Case study detail pages (`projects/*.html`) are self-contained documents sharing only `css/styles.css?v=3.0` and `assets/`.
- Mobile case study responsiveness is centrally governed from `css/styles.css:586-914` using `:is(.project-detail-body, body:has(header nav a[href*="index.html"]))`.
